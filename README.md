## 🚀 Quick Start

### Option 1: Deploy to Vercel (Recommended)

1. Fork this repository
2. Go to [vercel.com](https://vercel.com)
3. Click "Import Project"
4. Select this repository
5. Click "Deploy"
6. Done! Your site is live.

### Option 2: Deploy to Netlify

1. Download `index.html`
2. Go to [netlify.com](https://netlify.com)
3. Drag and drop the file
4. Done!

```bash

cd brightminds-landing
open index.html
```

No build step. No npm install. Just open and go.

## 🎨 Customization

### Changing Colors

All colors are CSS Custom Properties. Edit the `:root` section in `index.html`:

```css
:root {
    --primary: #6C5CE7;        /* Main brand color */
    --primary-light: #A29BFE;  /* Lighter accent */
    --primary-dark: #5A4BD1;   /* Darker shade */
    --secondary: #00CEC9;      /* Secondary accent */
    --accent: #FD79A8;         /* Highlight color */
    --text-primary: #16162a;   /* Headings */
    --text-secondary: #4A4A6A; /* Body text */
    --bg-primary: #FAFBFF;     /* Main background */
}
```

### Changing Text Content

All text is directly in the HTML. Open `index.html` and search for the text you want to change.

### Changing Fonts

Replace the Google Fonts link in `<head>` with your preferred font. Then update the `font-family` in the CSS.

### Adding/Removing Sections

Each section is clearly commented in the HTML:

```html
<!-- ========== FEATURES ========== -->
<section class="features">
    ...
</section>
```

Delete the entire `<section>` block to remove it.
